# 🎬 QUICK REFERENCE - GitHub Pages Live in 3 Steps

## 🎯 Your Goal
Get your site live at: **https://saaysalim.github.io/TestRepo**

---

## ⏱️ Time Required: 5 Minutes

---

## 🔴 STEP 1: Open Settings (30 seconds)

### Click Here:
```
https://github.com/saaysalim/TestRepo/settings
```

**Or manually:**
1. Go to: https://github.com/saaysalim/TestRepo
2. Click: **Settings** (top right)
3. Wait for page to load

✓ **You should see a left sidebar with many options**

---

## 🟡 STEP 2: Configure Pages (1 minute)

### In the left sidebar:
1. Scroll down to **"Code and automation"**
2. Click: **Pages** ← THIS ONE!

### You'll see:
```
Build and deployment
```

### Configure:
1. **Source**: Change to `Deploy from a branch`
2. **Branch**: Select `main`
3. **Folder**: Select `/ (root)`
4. Click: **Save** button

```
┌─────────────────────────────────────┐
│ 📍 Source: Deploy from a branch     │
│ 📍 Branch: main                     │
│ 📍 Folder: / (root)                 │
│ [     SAVE     ]                    │
└─────────────────────────────────────┘
```

✓ **GitHub will show your site URL**

---

## 🟢 STEP 3: Wait & Test (2-3 minutes)

### GitHub builds your site automatically

1. **Wait 2-3 minutes** ⏱️
2. **Go to**: https://saaysalim.github.io/TestRepo
3. **You should see**: 
   ```
   Welcome to TestRepo
   Getting Started | CI/CD Pipeline | API Reference
   ```

✓ **Your site is LIVE! 🎉**
