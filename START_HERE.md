### STEP 2️⃣: CONFIGURE DEPLOYMENT (1-2 minutes)

**Follow these steps:**

1. **Look for "Source" dropdown** (should say "GitHub Actions" by default)

2. **Look for "Branch" dropdown**
   - Click the dropdown
   - Select: `main`

3. **Look for "Folder" dropdown**
   - Click the dropdown
   - Select: `/ (root)` (the first option)

4. **Click the BLUE "Save" button**
   - Wait for the page to refresh
   - You should see: "Your site is live at: https://saaysalim.github.io/TestRepo"

## 🆘 IF SOMETHING GOES WRONG

### "I can't find the Pages option"
1. Make sure you're logged in to GitHub
2. Make sure you're on the right repository
3. Try direct link: https://github.com/saaysalim/TestRepo/settings/pages

### "Site shows 404 error"
1. Wait 2-3 more minutes (GitHub is still building)
2. Clear your browser cache (Ctrl+Shift+Delete)
3. Try visiting without the trailing slash: https://saaysalim.github.io/TestRepo

### "Build is taking too long"
1. Check the Actions tab: https://github.com/saaysalim/TestRepo/actions
2. Look for a workflow that's running
3. It's normal for it to take 2-3 minutes
4. Wait and refresh the page

### "Build failed with error"
1. Go to Actions tab: https://github.com/saaysalim/TestRepo/actions
2. Click on the failed workflow run
3. Click "Build" step to see error
4. Common fixes:
   - Try configuring Pages again
   - Wait 5 minutes and try again
   - Check if branch is set to "main"
